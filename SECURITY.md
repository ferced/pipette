# Security

If you find a vulnerability in Pipette or its infrastructure, please email **hola@ferced.com** instead of opening a public issue. We will reply within a few days.

Pipette stores no personal data: there are no accounts, and saved papers live only in the reader's browser. The only server-side input from readers is the sentence sent to `/api/rank` (For you), which is forwarded to the Jev API and not stored.
