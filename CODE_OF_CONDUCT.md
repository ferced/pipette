# Code of conduct

Pipette exists to make science easier to find for everyone. We want working on it to feel the same way.

- **Be kind and assume good faith.** Critique ideas and code, never people.
- **Welcome everyone,** whatever their background, field, experience or language. English and Spanish are both fine here.
- **Be precise about science.** When you disagree about a paper or a label, point to the text or the data.
- **No harassment,** discrimination, personal attacks or unwelcome attention, in issues, pull requests or anywhere else connected to the project.

Maintainers may edit or remove comments, and block people, when this code is not respected.

To report a problem privately, email **hola@ferced.com**. Reports are kept confidential.
